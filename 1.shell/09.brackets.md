# Shell脚本中常用到的括号整理

## 双引号 " "

双引号常用于包含一组字符串，在双引号中，除了 `$`、`\`、`(反引号)` 有特殊含义外，
其余字符（如IFS、换行符、回车符等）没有特殊含义。
```shell
$ a=3
$ echo "$a"
```
输出结果为 3，在双引号中 $ 符仍有特殊含义。

## 单引号 ' '

单引号的功能与双引号类似，不过单引号中的所有字符都没有特殊含义：
```shell
$ a=3
$ echo '$a'
```
输出结果为 $a，可见在单引号中 $ 符是不起作用的。

## 反引号 ` `
反引号的功能是命令替换，在反引号中的内容通常是命令行，程序会优先执行反引号中的
内容，并使用运行结果替换掉反引号处的内容。举个例子：
```shell
$ echo `date`
```
这行命令会先执行反引号中的命令 date，然后用 echo 命令打印出 date 命令的结果
（与直接使用 date 命令效果一样）。再举个例子：
```shell
#!/bin/bash

a=3
b=5
c=`expr $a \* $b`

echo $c

exit 0
```

## $ + 小括号 $( )
`$(...)` 的作用与反引号一样，也是命令替换：
```shell
#!/bin/bash

for file in $(ls /)
do
    echo $file
done

exit 0
```
这个脚本使用 for 循环打印根目录下所有文件的文件名，使用`$(ls /)`先获得根目录下的
所有文件，并将其作为参数列表传给 for 结构。

## < + 小括号 <( )

`<(command)` 是进程替换（process substitution）：把命令的输出包装成一个
"伪文件"，展开后得到一个文件路径（如 /dev/fd/63），目标命令可以像读文件
一样读取它。对应的 `>(command)` 把命令的输入当文件用，常用于 tee 等命令：
```shell
$ echo <(date)          # 输出：/dev/fd/63（一个路径，而非文本）
$ cat <(echo hello)     # 输出 hello，cat 把它当文件读
$ tee >(gzip > out.gz) < input   # 一边写屏幕一边喂给 gzip
```

### 与 $() 命令替换的区别

`$( )` 展开为输出文本（字符串），直接拼在命令行里；`<( )` 展开为文件路径，
供需要"读文件"的命令（如 diff、comm、paste）使用：

```shell
$ echo $(date)               # 输出：Mon Aug 10 12:00:00 CST 2026（文本）
$ touch $(date +%m%d).log    # 创建 0810.log，$() 展开为字符串
$ diff <(ls dir1) <(ls dir2) # diff 需要两个文件参数，<() 提供伪文件
```

| 对比项   | `$( )` 命令替换      | `<( )` 进程替换   |
|----------|----------------------|-------------------|
| 展开结果 | 文本字符串           | 文件路径          |
| 典型用途 | 作命令参数、变量赋值 | 当文件读          |
| 数据量   | 整体进参数/变量      | 边读边取          |
| 时序     | 同步执行完才替换     | 异步              |

### 与管道 | 的区别

在 bash 中（默认），管道两端的命令都在子 shell 中运行，循环里对变量的
修改会随子 shell 退出而丢失；`<( )` 使 while 循环在当前 shell 中运行，
赋值结果得以保留。这是"while 循环 + 进程替换"组合最常见的动机。
> 注：zsh 中管道的最后一段命令在当前 shell 中执行，该问题不明显；
> bash 则不同，这也是下方示例必须用 `<( )` 的原因。

### 典型应用：while 循环解析命令输出

以解析 adb devices 的输出为例，把每台设备的序列号、transport_id、usb
路径分别存进三个数组：

```bash
#!/bin/bash

# 模拟 adb devices -l 的输出
input=$'ABC123 device transport_id:7 usb:2-1.1\nDEF456 device transport_id:8 usb:3-2'

devSerIDList=()   # 序列号列表
devTPIDList=()    # transport_id 列表
devUsbPathList=() # usb 路径列表

while IFS=$'\t' read -r _sn _tp _usb; do
    devSerIDList+=("${_sn}")
    devTPIDList+=("${_tp}")
    devUsbPathList+=("${_usb}")
done < <(echo "${input}" | awk '$2=="device"{
    s=$1; t=""; u="";
    for(i=1;i<=NF;i++) {
        if($i~/^transport_id:/) t=substr($i,14);
        if($i~/^usb:/)          u=substr($i,5)
    }
    print s "\t" t "\t" u
}')

echo "序列号: ${devSerIDList[@]}"
echo "transport_id: ${devTPIDList[@]}"
echo "usb路径: ${devUsbPathList[@]}"
```

执行过程：awk 把每行整理成 `序列号<TAB>transport_id<TAB>usb路径` 三列，
`<( )` 把 awk 的输出变成伪文件，while 循环逐行读取，并按 `IFS=$'\t'` 以
制表符拆成三个变量，循环结束时三个数组均已填好：

```
序列号: ABC123 DEF456
transport_id: 7 8
usb路径: 2-1.1 3-2
```

如果改用管道，while 在子 shell 中运行，退出循环后数组为空：

```bash
# 错误写法（bash 默认）：管道组件在子 shell 中运行，数组结果丢失
# 注：zsh 中管道最后一段在当前 shell 执行，此问题不明显
devSerIDList=()
echo "$input" | while read -r _sn _tp _usb; do
    devSerIDList+=("${_sn}")
done
echo "${devSerIDList[@]}"    # bash 下输出为空！
```

> 注意：`<( )` 是 bash/zsh 特性，POSIX sh 不支持；`<( )` 中的命令异步执行。

## $ + 双小括号 $(( ))
`$(( ))` 的功能是进行算术运算，括号中的内容为数学表达式，使用 `$(( ))` 可以求数学
表达式的值：
```shell
#！/bin/bash

a=3
b=5
c=$(($a * $b))
echo $c

exit 0
```
上述脚本的输出结果为 15。

使用 `$(( ))` 进行数学运算时，不需要担心乘号等运算符被 shell 误解为其他含义，因为
它们都在括号内。

## $ + 中括号 $[ ]

`$[ ]` 的功能与 `$(( ))` 一样，都是用于算术运算。

## $ + 大括号 ${ }

### 变量替换

`${ }` 的功能是变量替换，类似于 `$`，但比 `$` 的替换范围更精准：

```bash
a=3; b=5
echo $ab       # 空，ab 被当作一个变量
echo ${a}b     # 3b，明确取 a 的值再拼接 b
```

### 几种特殊的替换结构

这四种替换结构用于根据变量是否为空，来决定最终的结果：
```bash
${var:-word}   # var 为空 → 返回 word；                      var 不为空 → 返回 var 的值
${var:=word}   # var 为空 → 返回 word，同时把 word 赋给 var；var 不为空 → 返回 var 的值
${var:+word}   # var 为空 → 返回空；                         var 不为空 → 返回 word
${var:?word}   # var 为空 → 报错退出，输出 word；            var 不为空 → 返回 var 的值
```

记忆技巧：注意符号的方向——
- `:` 后面跟着 `-`、`=`、`+`、`?` 四种操作符，含义各不相同。
- `-` 和 `=` 是"为空时兜底"的意思（var 缺值时才用 word 补上），`=` 多了一步"顺便赋值"。
- `+` 是"有值时替换"的意思，和前两个逻辑正好相反。
- `?` 是"为空时报错"，常用于检查必要变量是否已设置。
> 注意：四种结构中，只有 `${var:=word}` 会修改 var 本身的值，其余三种都只产生替换结果，
> 不会改变 var。

下面逐个举例说明：

1. `${var:-word}` —— 为空时给个默认值
```shell
$ name=""
$ echo ${name:-guest}
guest                          # name 为空，返回默认值 "guest"
$ echo $name
                               # name 仍然是空，值没有被改变

$ name="alice"
$ echo ${name:-guest}
alice                          # name 不为空，返回 name 自身的值
```

2. `${var:=word}` —— 为空时赋默认值（和 `-` 类似，但会修改 var 本身）
```shell
$ name=""
$ echo ${name:=guest}
guest                          # name 为空，返回 "guest"，同时 name 被赋值为 "guest"
$ echo $name
guest                          # name 已经被改写了

$ name="alice"
$ echo ${name:=guest}
alice                          # name 不为空，不做任何修改，返回 name 自身的值
```

3. `${var:+word}` —— 不为空时替换（和 `-` 逻辑相反）
```shell
$ name="alice"
$ echo ${name:+hello}
hello                          # name 不为空，返回 "hello"

$ name=""
$ echo ${name:+hello}
                               # name 为空，什么都不返回（返回空）
```

4. `${var:?word}` —— 为空时报错退出（常用于检查必须设置的变量）
```shell
$ name=""
$ echo ${name:?请设置 name 变量}
bash: name: 请设置 name 变量    # name 为空，将 word 输出到 stderr，脚本退出

$ name="alice"
$ echo ${name:?请设置 name 变量}
alice                          # name 不为空，正常返回值
```

> 补充：word 不一定是固定的字符串，也可以是另一个变量或命令的输出，例如 `${var:-$HOME}` 或 `${var:-$(date)}`。

### 不带冒号的存在性判断 ${var+word}

上面四种都带 `:`，判断的是变量是否**为空**；去掉 `:` 后，判断的是变量是否**已定义**
（有值或空串都算“存在”）：

```bash
${var+word}    # var 已定义(含空串) → word；未定义 → 空
${var-word}    # var 未定义 → word；已定义 → var 的值
${var=word}    # var 未定义 → 赋值并返回 word
${var?word}    # var 未定义 → 报错退出
```

最常用的是 `${var+x}`：用一个固定的 `x` 把“存在性”探测出来，等价于
“var 是否已设置（哪怕是空串）”。例如 NO_COLOR 规范要求“只要设置了就关色，
空值也算”，就可以写：

```bash
if [ -n "${NO_COLOR+x}" ]; then
    echo "NO_COLOR 已设置, 关闭颜色"
fi
```

带 `:` 与不带 `:` 的对比：

```bash
unset v;  echo "[${v+x}][${v:-default}]"   # [][default]
v="";     echo "[${v+x}][${v:-default}]"   # [x][default]
v="hi";   echo "[${v+x}][${v:-default}]"   # [x][hi]
```

可见 `${v+x}` 在 `v` 为空串时仍返回 `x`（视为已设置），而 `${v:-default}`
把它当“空”处理。

### 间接引用

`${!var_name}` 中 `!` 表示间接引用——先用 `var_name` 的值作为变量名，再取那个变量的值：

```bash
$ target="hello"
$ var_name="target"
$ echo ${!var_name}
hello                             # 等价于 ${target}
```

典型用途是根据运行时确定的变量名来动态取值：

```bash
# 根据用户选择访问不同变量
$ level_debug=1
$ level_info=2
$ level_warn=3
$ mode="info"
$ var_name="level_$mode"
$ echo ${!var_name}              # 间接引用 level_info → 2
```

位置参数同样适用：`${!1}` 表示用 `$1` 的值作为变量名再取值，常用于
“字段名 → 变量”的映射：

```bash
# 把字段名当参数传入, 取出同名变量的值
$ width=64; height=48
$ set -- width
$ echo "${!1}"        # 64,  等价于 $width
$ set -- height
$ echo "${!1}"        # 48
```

`${!1}`、`${!2}` 与 `${!var_name}` 原理相同，只是把“名字来源”换成了位置参数。
典型用法是写一个按名取值的函数：

```bash
function field_value() {
    _fv="${!1}"       # $1 是字段名, 取出对应变量的值到 _fv
}
# field_value width  →  _fv=64
```

> 注意：若 `$1` 为空或不是合法变量名，`${!1}` 会报 `bad substitution`，
> 使用前应先校验名字是否合法。

> 注意：`${!var_name}` 是 Bash 特有的语法，Zsh 中需要使用 `${(P)var_name}` 来实现相同功能。

### 子字符串截取

单个冒号 `:` 的含义取决于冒号前是谁：
- 普通变量（`${var:N}`）→ **字符偏移**，从第 N 个字符开始截取
- 特殊参数（`${@:N}`、`${*:N}`）→ **参数切片**，从第 N 个位置参数开始

```bash
${var:offset}        # 从 offset 位置截取到末尾
${var:offset:length} # 从 offset 位置截取 length 个字符
```

offset 从 0 开始：

```shell
$ str="Hello, World!"
$ echo ${str:0:5}        # Hello
$ echo ${str:7:5}        # World
$ echo ${str:7}          # World!
```

负数 offset 表示从末尾倒数：

```shell
$ echo ${str: -5}        # orld!  （注意冒号和负号之间要有空格）
$ echo ${str: -5:2}      # or
```

> 注意：负数 offset 时，冒号和负号之间必须有空格，否则会被识别为 `${var:-word}` 默认值语法。

同样的截取语法也适用于 `$*` 和 `$@`，用于从位置参数中切片：

```shell
${*:2}        # 从第 2 个参数开始，拼成一个字符串
${@:2}        # 从第 2 个参数开始，每个参数保持独立
${@:2:3}      # 从第 2 个参数开始，取 3 个参数
```

实际应用——跳过脚本自身的参数，将剩余参数传递给其他命令：

```shell
# 用法: ./script.sh --verbose file1 file2 file3
# 跳过第 1 个参数 --verbose，打印剩余参数
printf "%-40s%s\n" "$1" "${@:2}"
```

## 小括号 ( )

小括号有两种用途：数组初始化和命令组（子 shell）。

### 数组初始化

```bash
array1=(1 2 3 4 5)
array2=(one two three four five)
```

通过 `${array[index]}` 访问元素，索引从 0 开始：

```bash
$ echo ${array1[2]}        # 取第 3 个元素
$ 3

$ echo ${array2[0]}        # 取第 1 个元素
$ one

$ echo ${array2[*]}        # 输出整个数组
$ one two three four five
```

> 注意：数组变量的可移植性并不好，在 shell 编程中使用得不多。

### 命令组（子 shell）

`()` 将多条命令组成一个整体，在**子 shell** 中顺序执行。子 shell 中的变量修改、`cd`、
`exit` 等都不会影响当前 shell：

```bash
# 变量隔离
a=1; (a=2; echo "子 shell: a=$a"); echo "当前 shell: a=$a"
# 子 shell: a=2
# 当前 shell: a=1

# cd 隔离
pwd              # /home/user
(cd /tmp; pwd)   # /tmp
pwd              # /home/user

# exit 隔离：只退出子 shell，不影响当前 shell
(exit 0; echo "不会执行")
echo "当前 shell 仍在运行"
```

与 `{ }` 的区别：`{ }` 也在当前 shell 中组成命令组，但变量修改、`cd` 等会影响当前 shell，
且语法上最后一个命令后必须有 `;`，左括号前必须有空格：

```bash
# () —— 隔离环境
a=1; (a=2); echo $a    # 输出 1

# {} —— 共享环境
a=1; { a=2; }; echo $a  # 输出 2
```

### 行内变量赋值

`VAR=value command` 写法中，`VAR=value` 只对 `command` 生效，不会泄露到当前 shell：
```bash
MY_VAR=hello
MY_VAR=world echo $MY_VAR    # 输出 hello（$MY_VAR 在赋值前就展开了）
MY_VAR=world printenv MY_VAR  # 输出 world（printenv 看到了环境变量）
echo $MY_VAR                  # 输出 hello（当前 shell 未变）
```

行内赋值无论加不加 `()` 都不会泄露变量，加括号的区别在于命令在子 shell 中执行：
```bash
# 不加括号：cd 会影响当前 shell
MY_VAR=hello cd /tmp && pwd   # 当前 shell 已切换到 /tmp

# 加括号：cd 只影响子 shell
(MY_VAR=hello cd /tmp)
pwd  # 仍在原来的目录
```

实际应用举例：临时修改环境变量运行程序，用完自动恢复
```bash
# 临时指定 ADB 路径启动 scrcpy
(ADB="/path/to/custom_adb" scrcpy)

# 临时指定 GOBIN 编译安装
(GOBIN="$HOME/local/bin" go install ./...)

# 临时切换语言环境
(LC_ALL=C sort file.txt | uniq)
```

## 双小括号 (( ))
双小括号命令允许在比较过程中使用高级数学表达式：
```shell
(( expression ))
```
其中，expression 可以是任意的数学赋值或表达式。相比 test 命令只能在比较中使用简单
的算术操作，双小括号命令提供了更多的数学符号，可以在双小括号中进行各种逻辑运算、
数学运算，也支持更多的运算符（如 ++、-- 等）。

常使用的双小括号来在 for 循环中实现 C 语言风格的迭代：
```shell
#!/bin/bash

for ((i = 0; i < 10; i++))
do
    echo -n "$i "
done
echo ""

exit 0
```
如果不使用双括号, 则为for i in `seq 0 4` 或者 `for i in {0 1 2 3 4}`。再如可以
直接使用 `if (($i<5))`, 如果不使用双括号, 则为`if [ $i -lt 5 ]`。

## 中括号 [ ]
单个的中括号的功能与 test 命令一样，都是用作条件测试。
```shell
#!/bin/bash

read -p "please enter a number: " num

if [ $num -gt 10 ]; then
    echo "num > 10"
else
    echo "num <= 10"
fi
```

## 双中括号 [[ ]]
双中括号提供了针对字符串比较的高级特性，使用双中括号 [[ ]] 进行字符串比较时，可以
把右边的项看做一个模式，故而可以在 [[ ]] 中使用正则表达式：
```shell
#！/bin/bash

if [[ hello == hell* ]]; then
    echo "equal"
else
    echo "unequal"
fi

exit 0
```

## 大括号 { }
大括号用于括起一个语句块。如果需要在某些只能使用单个语句的地方（如AND、OR列表中）
使用多条语句，则可以用大括号将这多条语句括起来构造一个语句块。
单大括号，{ cmd1;cmd2;cmd3;} 在当前shell顺序执行命令cmd1,cmd2,cmd3, 各命令之间
用分号隔开, 最后一个命令后必须有分号, 第一条命令和左括号之间必须用空格隔开。

例如要让 `&&` 作用于多个测试，就必须先用 `{ }` 把它们括成一组（`!` 直接作用于
两条独立的 `[ ]` 并不等价）：

```bash
# stdout 与 stderr 都不是终端时才关闭颜色
_on=1
{ [ ! -t 1 ] && [ ! -t 2 ]; } && _on=0
```

总结：

| 功能                                     | 符号             |
|------------------------------------------|------------------|
| 引用字符串，字符串中部分特殊符号有意义   | 双引号""         |
| 引用字符串，字符串中特殊符号全都没有意义 | 单引号''         |
| 命令替换                                 | (反引号)，`$()`  |
| 进程替换                                 | <() 和 >()       |
| 算数运算                                 | $(())、$[]、(()) |
| 变量替换                                 | ${}              |
| 数组初始化                               | ()               |
| 条件测试                                 | []               |
| 字符串比较                               | [[ ]]            |
| 括起一个语句块                           | { }              |


对{}和()而言, 括号中的重定向符只影响该条命令， 而括号外的重定向符影响到括号中的所有命令。
